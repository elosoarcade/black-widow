# Black Widow
**Black Widow MCBE Add-On brings this dangerous, small, and poisonous spider into your world, which can be lethal if it catches you by surprise.**

The Black Widow doesn't deal damage with its bite, but inflicts the Wither effect for 30 seconds, which can be lethal. It only has one heart of health, so you can eliminate it with a single punch. Additionally, its eyes and the red marking on its abdomen glow faintly in the dark, helping you spot it before it attacks... sometimes.

- ❤️ Health: 1
- ⚔️ Attack: Wither effect for 30 s.
- ✨ EXP: 1
